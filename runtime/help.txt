Usage: pp-pal COMMAND [OPTIONS]

Updates:
  --update [--file PATH] [--config PATH]  Validate and activate released pairs locally.
  Requires a stable wrapper bootstrap release; no usable release exists yet.

Commands:
  holdings   Show recorded quantities by security and securities account.
  history    Show recorded transactions, including closed holdings and dividends.
  purchase   Preview a same-currency purchase after mandatory release validation.
  configure  Save portfolio path and resolved default account IDs explicitly.
  backup-monthly  Check due launch protection without loading the financial model.
  backup-before-update  Preserve an exact snapshot before an actual upgrade attempt.

Shared options:
  --file PATH                 Override selected portfolio (relative to cwd).
  --config PATH               Select UTF-8 pp-pal.properties configuration.
  --securities-account ID|NAME  Stable ID or exact unique securities account name.
  --cash-account ID|NAME      Stable ID or exact unique cash account name.
  --help                     Show this help without Docker or a portfolio.

Holdings options:
  --security IDENTIFIER|TEXT  Exact ID/ISIN/WKN/ticker, or name substring.
  --sort updated|name|quantity  Default updated, descending.
  --ascending                Reverse the primary sort; stable ties remain ascending.
  --include-zero             Include closed holdings.
  --limit NUMBER             Default 15; 0 means unlimited.

History options:
  --security IDENTIFIER|TEXT  Same exact identifier/name filters as holdings.
  --type purchase|sale|dividend  Select a recorded transaction type.
  --from YYYY-MM-DD          Inclusive start date.
  --to YYYY-MM-DD            Inclusive end date.
  --sort date                Newest first; --ascending reverses dates only.
  --limit NUMBER             Default 15; 0 means unlimited.
  Shared-cash dividends appear once; ambiguous securities attribution is marked.

Purchase preview options:
  --security ID|IDENTIFIER|NAME  Exact existing security; no fuzzy names.
  --security-id UUID          Stable ID; combine identifiers to disambiguate.
  --isin ISIN | --wkn WKN | --ticker TICKER  Exact identifier constraints.
  --quantity DECIMAL         Positive shares, exact 8-place scale.
  --price DECIMAL             Positive unit price, exact 8-place scale.
  --gross DECIMAL             Gross value; or --total DECIMAL booked debit.
  --fees DECIMAL --taxes DECIMAL  Exact cents; omitted costs default zero.
  --date YYYY-MM-DD           Required date; --time HH:MM[:SS[.fraction]].
  Missing time uses 11:00:00. Both accounts are required, explicit or configured.
  Price/gross/total must determine and agree on the amount. Preview never applies.

Configuration defaults: pp-pal.properties in cwd; portfolio_performance.xml in cwd.
Configured file paths resolve relative to the configuration directory.
Queries preserve portfolio, metadata and configuration. No live prices or profit.
Launches create a due Berlin monthly backup; each backup-before-update call creates
another exact backup. That command does not discover, build or activate updates.
Exit codes: 0 success; 2 input/validation rejected; 3 operational failure;
4 reserved for a completed financial change with failed follow-up work.
Financial application, sales, dividends and statement import are pending.
