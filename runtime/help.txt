Usage: pp-pal COMMAND [OPTIONS]

Updates:
  --update [--file PATH] [--config PATH]  Validate and activate released pairs locally.
  Requires a stable wrapper bootstrap release; no usable release exists yet.

Commands:
  holdings   Show recorded quantities by security and securities account.
  history    Show recorded transactions, including closed holdings and dividends.
  purchase   Preview or apply a same-currency purchase after mandatory release validation.
  sale       Preview or apply a sale with complete holding-history validation.
  dividend   Preview or apply a security-associated cash credit with fees/taxes.
  import     Preview all purchases in one proved Baader EUR statement PDF.
  configure  Save portfolio path and resolved default account IDs explicitly.
  backup-monthly  Check due launch protection without loading the financial model.
  backup-before-update  Preserve an exact snapshot before an actual upgrade attempt.

Shared options:
  --file PATH                 Override selected portfolio (relative to cwd).
  --config PATH               Select UTF-8 pp-pal.properties configuration.
  --securities-account ID|NAME  Stable ID or exact unique securities account name.
  --cash-account ID|NAME      Stable ID or exact unique cash account name.
  --help                     Show this help without Docker or a portfolio.

Holdings options:
  --security IDENTIFIER|TEXT  Exact ID/ISIN/WKN/ticker, or name substring.
  --sort updated|name|quantity  Default updated, descending.
  --ascending                Reverse the primary sort; stable ties remain ascending.
  --include-zero             Include closed holdings.
  --limit NUMBER             Default 15; 0 means unlimited.

History options:
  --security IDENTIFIER|TEXT  Same exact identifier/name filters as holdings.
  --type purchase|sale|dividend  Select a recorded transaction type.
  --from YYYY-MM-DD          Inclusive start date.
  --to YYYY-MM-DD            Inclusive end date.
  --sort date                Newest first; --ascending reverses dates only.
  --limit NUMBER             Default 15; 0 means unlimited.
  Shared-cash dividends appear once; ambiguous securities attribution is marked.

Purchase options:
  --security ID|IDENTIFIER|NAME  Exact existing security; no fuzzy names.
  --security-id UUID          Stable ID; combine identifiers to disambiguate.
  --create-security          Explicitly create if supplied identifiers match none.
  --name NAME --currency CODE Required definition with --create-security.
                             Matching identifiers reuse unchanged existing data.
  --isin ISIN | --wkn WKN | --ticker TICKER  Exact identifier constraints.
  --quantity DECIMAL         Positive shares, exact 8-place scale.
  --price DECIMAL             Positive unit price, exact 8-place scale.
  --gross DECIMAL             Gross value; or --total DECIMAL booked debit.
  --fees DECIMAL --taxes DECIMAL  Exact cents; omitted costs default zero.
  --date YYYY-MM-DD           Required date; --time HH:MM[:SS[.fraction]].
  Missing time uses 11:00:00. Both accounts are required, explicit or configured.
  Price/gross/total must determine and agree on the amount. Default is preview.
  --apply --desktop-closed    Commit a fresh validated purchase with PP closed.
  --recover-write --desktop-closed  Finish verified pending cleanup only; no inputs.
  Apply uses a per-portfolio writer lock; Portfolio Performance does not use it.
  Daily backups are exact original snapshots; committed cleanup failures exit 4.
  Never repeat an apply reported as committed; recover the pending cleanup.

Sale options:
  Existing-security selectors, accounts, decimals, dates and write options as above.
  --total is booked cash credit: gross minus fees and taxes; negative credit rejects.
  Missing time uses 11:00:01, disclosed in preview; explicit times stay unchanged.
  The entire selected security/securities-account history must remain nonnegative.
  At equal timestamps increases precede decreases; persisted account-list order
  breaks ties within each group, with the new sale after existing decreases.
  Partial/full sales preserve definitions and history; no FIFO/profit is calculated.

Dividend options:
  Existing-security selectors and cash-account selection as above; no securities
  account is required. --gross or --total must determine the cash credit.
  --total is booked credit; gross = booked + fees + taxes, exact cents.
  Omitted fees/taxes default zero; contradictory amounts and negative credits reject.
  --date YYYY-MM-DD is required; --time preserves supplied time, or uses 11:00:00.
  Default preview shows choices and derivations. --apply --desktop-closed records
  one same-currency cash dividend, including for a closed holding. Quantity and
  holding last updated stay unchanged; history uses reference-cash/security relevance.
  Shared cash can make attribution ambiguous; no securities-account link is created.
  Shared atomic-write, backup and --recover-write rules apply. FX remains pending.

PDF purchase preview:
  import --pdf PATH          One readable .pdf; preview only, no --apply.
  Requires existing securities and selected securities/cash accounts.
  Supported: synthetic German Baader EUR flat single-page or page 1/1 members.
  Every member/page must be covered. Other banks, continuations, FX, sale and
  dividend layouts reject the whole document. Smartbroker branding is insufficient.
  Purchase options supplement only absent fields; conflicting present values reject.
  Absent quantity/price section needs both values; absent booked debit needs --total.
  Financial supplements require a single member. Origins show PDF, SUPPLEMENT,
  derivation/defaults or fallback 11:00:00; explicit midnight remains midnight.

Configuration defaults: pp-pal.properties in cwd; portfolio_performance.xml in cwd.
Configured file paths resolve relative to the configuration directory.
Queries preserve portfolio, metadata and configuration. No live prices or profit.
Launches create a due Berlin monthly backup; each backup-before-update call creates
another exact backup. That command does not discover, build or activate updates.
Exit codes: 0 success; 2 input/validation rejected; 3 operational failure;
4 completed financial change with failed follow-up work.
Sale/dividend/FX statement layouts and PDF application are pending.
