- [ ] Apply shared financial/update/duplicate/metadata/safe-write rules; mixed purchase/dividend documents validate all members together and failed members leave financial data unchanged.
- [ ] Verify fees/taxes, closed holdings, quantity/holding-last-updated invariance, relevance, repeat imports, supplements and document atomicity through real PDF commands; retain older layout regressions and extend support/extractor/updater evidence.
