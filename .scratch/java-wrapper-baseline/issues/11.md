## What to build

Preview and record manual foreign-currency transactions with explicit exchange information and preserved upstream currency/rate semantics.

## Acceptance criteria

- [ ] Accept determined monetary inputs and explicit required exchange rates; preserve currencies, gross/booked amounts, fees, taxes, and upstream exchange semantics without fetching rates.
- [ ] Show rates, currencies, supplied/derived values and rounding in preview; reject missing rates, contradictory amounts or unrepresentable precision.
- [ ] Apply purchase/sale/dividend entries through existing quantity validation, update, preview, atomic replacement and backup paths.
- [ ] Inspect saved financial units/rates and account/security links using pinned core; cover all three transaction types, supported decimal boundaries and rejection without changes in command tests and update gates.
