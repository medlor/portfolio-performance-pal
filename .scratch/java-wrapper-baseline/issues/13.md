## What to build

Convert one supported purchase PDF headlessly and preview all recognized transactions with authoritative booked amounts and explicit missing-value supplementation.

## Acceptance criteria

- [ ] Establish anonymized representative PDFs, line-preserving extracted-text fixtures and independent expected records. Select the upstream extractor using verified bank identifiers and layout, not Smartbroker branding alone.
- [ ] Run updates before processing, fix the invocation engine, and use the real upstream PDF-to-text and extraction path. Verify input/mount/ownership behavior on Linux.
- [ ] Extract security, quantities, amounts, fees/taxes, dates/times, currencies and broker references as present; booked amount is authoritative. CLI supplementation may only complete missing information, is identified in preview, and cannot override conflicting extracted financial values.
- [ ] Use purchase fallback 11:00:00 only when time is missing. Unsupported, ambiguous, incomplete, contradictory or invalid members prevent applying the entire document; preview never records changes.
- [ ] Restrict to one PDF per command; record only fixture-tested layouts and exact revisions/images in support evidence. Verify conversion as well as text extraction, supplements and rejection; extend candidate gates and extractor guide.
