## What to build

Run a short-lived container command to inspect holdings in the selected supported portfolio with predictable paths, account selection, filters, sorting, and limits.

## Acceptance criteria

- [ ] Document command/error conventions and a configuration filename/format; discover configuration in the working directory or use --config, with portfolio_performance.xml as the default portfolio.
- [ ] Apply --file and explicit account overrides; resolve configured relative paths from the configuration directory and explicit file paths from the working directory. Resolve stable account IDs or exact unique names and store IDs in configuration; reject missing/ambiguous required selections.
- [ ] Group quantities by security and securities account; filter by security identifier/name and securities account, sort by name, quantity, or holding last updated, default to newest quantity updates, and omit zero holdings by default.
- [ ] Use stable tie ordering and --limit default 15, with zero unlimited. Show simple text quantities without live valuations or calculated profit; dividends and metadata changes do not affect holding last updated.
- [ ] Exercise real Linux mounts, paths with spaces, file ownership/permissions, unsupported inputs, and all promised query controls against temporary portfolios. Reads do not persist migrations or mutate financial data/import metadata.
