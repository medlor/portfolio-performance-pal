## What to build

Preview and record dividend cash credits for an existing security without changing held quantity or holding last updated.

## Acceptance criteria

- [ ] Resolve required security and cash account unambiguously; show gross/booked values, fees/taxes, choices and derivations through upstream monetary models.
- [ ] Preserve explicit time or use disclosed 11:00:00 fallback; reject inconsistent amounts or missing/ambiguous required selections.
- [ ] Apply through shared update, preview, stale-input, atomic-write and backup rules; dividends on closed holdings retain correct references and appear with the documented history relevance.
- [ ] Verify fees/taxes, amount derivations, closed holdings, quantity/timestamp invariance, linked relevance, preview immutability and candidate validation through real commands.
